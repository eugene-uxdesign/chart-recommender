# chart-recommender

Raw 데이터(엑셀 파일 또는 텍스트 설명)와 그 데이터를 보여주려는 목적(자유 문장)을 입력받아, 어떤 차트 유형이 가장 적합한지 근거와 함께 추천하고 실제 시각화까지 생성해주는 [Claude Skill](https://docs.claude.com/en/docs/agents-and-tools/agent-skills)입니다.

결과물이 PPT나 데스크탑 화면처럼 **가로가 긴 직사각형(와이드) 레이아웃**에 들어가는 것을 전제로, 데이터 구조 → 목적 문장 해석 → 차트 후보 매핑 → 와이드 레이아웃 적합도 필터링까지 거쳐 최종 추천을 제시합니다.

## 핵심 원칙

1. 목적은 자유 문장으로만 받는다. ("비교/추이/구성 중 고르세요" 같은 고정 선택지를 사용자에게 강요하지 않음)
2. 데이터 구조(필수 조건)가 목적 문장의 의도보다 항상 우선한다.
3. 최종 결과물이 가로가 긴 화면에 들어간다는 전제를 항상 반영한다 (원형/방사형 차트는 감점, 대체 차트 우선).
4. 카테고리 개수 같은 임계치는 고정 숫자로 사전 차단하지 않고, 시각화 생성 후 사후 코멘트로 조정 여부를 안내한다.

## 구조

```
chart-recommender/
├── SKILL.md                       # 트리거 조건 + 전체 실행 흐름 (6단계)
└── references/
    ├── data-patterns.md           # 데이터 성격(패턴 유형) 15종
    ├── chart-catalog.md           # 차트 유형 25종 + 가로형(와이드) 적합도
    ├── mapping-rules.md           # 의도(목적 문장) × 데이터 구조 매핑 규칙 11종
    └── scan-procedure.md          # 데이터 스캔 절차 (컬럼 프로파일링 → 구조 판별 → 규모 지표)
```

## 실행 흐름

```
1. 입력 파악          → 파일이 있는가, 설명 텍스트만 있는가 확인 (분기)
2. 데이터 스캔        → 컬럼 프로파일링 → 구조 태그 판별 → 규모 지표 산출
3. 목적 문장 해석      → 의도 신호 추출 (복수 가능, 강도 판단)
4. 교차 매핑          → 데이터 구조(필수조건) ∩ 의도(보조조건) → 후보 압축
5. 레이아웃 필터       → 와이드 화면 적합도로 최종 순위 재조정
6. 추천 + 시각화 생성  → Top 1~2안 근거와 함께 제시, 실제 차트 렌더링
```

## 사용 방법

가장 간단한 방법은 이 레포에 있는 **`chart-recommender.skill`** 파일을 다운로드해서 [claude.ai](https://claude.ai)의 Skill 업로드 기능으로 바로 등록하는 것입니다.

또는 `chart-recommender/` 폴더(SKILL.md + references)를 직접 Claude의 skills 디렉토리에 배치해도 됩니다.

사용 시에는 아래처럼 입력하면 됩니다.

- Raw 데이터: 엑셀/CSV 파일 첨부, 또는 "출처별로 몇 건씩 들어와서 단계를 거쳐 해결되는 데이터가 있어" 같은 텍스트 설명
- 목적: 자유 문장 (예: "사용자는 취약점의 다양한 출처로부터 해결까지의 여정을 한눈에 볼 수 있어야 한다.")

## 상태

초안(draft) 단계입니다. 실제 데이터로 테스트 케이스를 만들어 검증하고, 트리거 정확도(description)를 다듬는 과정이 아직 남아 있습니다.
