# 데이터 스캔 절차

`mapping-rules.md`의 "필수 조건/보조 조건"을 사람이 눈으로 보지 않아도 Raw 데이터만으로 판별하기 위한 절차. 컬럼 단위 프로파일링 → 데이터셋 단위 구조 판별 → 규모 지표 산출 순서로 진행한다.

## 0. 입력 형식 분기

| 입력 | 처리 방식 |
|---|---|
| 엑셀/CSV 등 실제 파일 | `xlsx` skill(또는 해당 파일 skill)로 직접 열어서 **실측 프로파일링** — 아래 Step A~C를 실제 값으로 계산 |
| 사용자의 설명(텍스트)만 존재 | **추정 프로파일링** — 문장에서 컬럼 구조를 역으로 추론 (예: "출처별로 몇 건씩 들어와서 단계를 거쳐 해결되는 데이터" → 출처=범주형, 단계=순서형, 건수=수치형). 규모 지표는 사용자가 언급한 대략치나 "많음/적음" 같은 정성적 표현에 의존. 구조 추론이 애매해서 추천이 크게 갈리는 지점에서만 최소한의 확인 질문을 한다 |

두 경우 모두 결과는 아래 Data Profile 포맷으로 정리하되, 추정 프로파일링의 경우 각 항목에 "추정치"임을 암묵적으로 인지하고 추천 시 확신도를 낮춰 표현한다(예: 단정적 어조 대신 "~일 가능성이 높다").

## Step A. 컬럼 단위 프로파일링

각 컬럼마다 아래를 판별한다.

| 판별 항목 | 판별 방법 | 결과값 |
|---|---|---|
| 데이터 타입 | 값 파싱 시도 | 수치형 / 문자열(범주형) / 날짜-시간 / 불리언 / 좌표 |
| 카디널리티 | 고유값 개수 / 전체 행 수 | 낮음(범주형 확정) / 높음(식별자·연속형 가능성) |
| 날짜-시간 여부 | 포맷 패턴 매칭 + 순서 정렬 시도 | 시간축 후보 여부 |
| 결측치 비율 | null/빈값 카운트 | 낮음/중간/높음 |
| 값 범위·분포 | min/max, 음수 포함 여부, 분산 | 편차·분포 판별에 사용 |
| 계층 힌트 | 컬럼명에 parent/child, 상위/하위, level 등, 또는 값에 구분자(`/`, `>`) | 계층 구조 후보 여부 |
| 관계형 힌트(노드-엣지) | 컬럼 2개가 "출발-도착"(from-to, source-target) 유사 네이밍 + 같은 값 집합을 공유 | 흐름/네트워크 구조 후보 여부 |
| 지리 힌트 | 컬럼명에 country/region/lat/lng, 값이 국가코드·지역명 패턴 | 공간 데이터 후보 여부 |

## Step B. 데이터셋 구조 판별 (컬럼 조합 패턴)

컬럼별 태그 조합으로 구조 유형을 결정한다. **배타적이지 않으며, 복수 태그가 동시에 붙을 수 있다.**

| 구조 패턴 | 판별 조건 | 연결되는 의도 축 |
|---|---|---|
| 단순 집계표 | 범주형 1 + 수치형 1(행마다 유일 조합) | 비교 |
| 시계열 구조 | 날짜-시간 1 + 수치형 1 이상, 시간순 정렬 시 규칙적 간격 | 추세 |
| 다중 시리즈 시계열 | 위 + 범주형(시리즈 구분자) 추가 | 추세 + 비교 |
| 구성/비율 구조(후보) | 범주형 1 + 수치형 1, 수치형 합이 의미 있는 전체를 이룸 (아래 "구성 판별 가중치" 참고) | 구성 |
| 노드-엣지 구조 | "출발-도착" 컬럼 쌍 + 그 사이 이동량(가중치) 수치 | 흐름/여정 |
| 선형 단계 구조 | 노드-엣지와 유사하나 고정된 순서의 단계 + 값이 단조 감소 경향 | 흐름 중 Funnel 특화 |
| 계층 구조 | 계층 힌트 컬럼 + 수치형(크기) | 계층 |
| 분포 구조 | 수치형 1, 각 행이 집계값 아닌 개별 관측치 | 분포 |
| 상관 구조 | 수치형 2 이상, 각 행이 개별 관측 단위 | 관계 |
| 다변량 구조 | 수치형 3 이상 + 범주형(개체 식별) | 다변량 |
| 공간 구조 | 지리 힌트 컬럼 존재 | 공간 |
| KPI 단일값 구조 | 행 수 매우 적음(1~2) 또는 "현재값-목표값" 컬럼 쌍 | 단일 지표 |

### 구성/비율(Composition) 판별 가중치

구성 여부는 이 단계에서 확정하지 않고 "후보 플래그"만 단다. 최종 확정은 `mapping-rules.md`의 3번(구성/비율) 규칙에서 아래 순서의 가중치로 처리한다:

1. **컬럼명 시그널 (최우선)**: `percentage`, `ratio`, `share`, `점유율`, `비중`, `비율` 등이 컬럼명에 있으면 구성 확정. `count`, `amount`, `수량`, `건수`는 구성일 수도 단순 비교일 수도 있으므로 다음 단계로.
2. **목적 문장 문맥**: "차지하는", "비중", "구성", "전체 중" 같은 표현이 목적 문장에 있으면 구성 판단 가중치 부여.
3. **수치 검증 (보조적 확인)**: 합산 근사치(95~105% 등)가 나오면 신뢰도를 더하는 정도로만 사용. 단독 판단 근거로는 쓰지 않는다(우연히 합이 100 근처인 비-구성 데이터도 많기 때문).

## Step C. 규모(Scale) 지표 산출

`mapping-rules.md`의 보조 조건 대부분이 개수 기준이므로, 아래 지표를 별도로 산출한다.

| 지표 | 계산 방법 | 어디에 쓰이나 |
|---|---|---|
| 주 범주형 컬럼의 고유값 개수 | distinct count | Bar vs Ranked Bar vs Top-N 전환 기준 |
| 시리즈(그룹) 개수 | 2차 범주형 컬럼의 고유값 개수 | Line 개별 표시 vs Small Multiples 전환 기준 |
| 시간 포인트 개수/간격 | 시간축 고유값 개수, 간격 규칙성 | 시계열 차트 해상도 판단 |
| 개별 관측치 총 행 수 | row count | 분포 차트에서 Histogram(대량) vs Dot Plot(소량) 판단 |
| 계층 깊이 | 계층 컬럼 개수 또는 구분자 분할 최대 깊이 | Treemap vs Sunburst vs Tree Diagram |
| 노드 개수 (출발+도착 고유값 합) | distinct count of source ∪ target | Sankey 복잡도 판단, 너무 많으면 상위 N개 집계 플래그 |

### 임계치 판단 원칙 (고정 숫자 대신 상대적 판단)

카테고리 7개, 시리즈 5개 같은 고정 숫자로 사전 차단하지 않는다. 대신 **"레이블/구조가 겹치지 않고 온전히 표시 가능한가"**를 기준으로 상대적으로 판단한다.

| 판단 대상 | 유동적 판단 로직 |
|---|---|
| 카테고리 개수(Bar 관련) | 라벨 간 간섭이 예상되는 수준이면 → Top-N + 기타 묶음 또는 정렬형으로 전환 제안 |
| 시리즈 개수(Line 관련) | 색상으로 구분·추적 가능한 수준을 넘으면 → Small Multiples 전환 제안 |
| 노드 개수(Sankey 관련) | 링크 교차가 심해져 구조를 읽기 어려워지는 수준을 넘으면 → 상위 항목 집계 제안 |

**운영 방식: 사전 차단이 아니라 사후 경고 + 대안 제시.** 먼저 시각화를 생성한 뒤, "카테고리가 많아 라벨이 겹칠 수 있습니다. Top 10 + 기타로 묶을까요?" 같은 코멘트를 함께 제시하는 방식으로 처리한다. 이렇게 하면 애매한 경계선 케이스에서 과도하게 보수적으로 판단해 좋은 차트를 걸러버리는 것을 방지할 수 있다.

## Step D. 레이아웃 필터와의 연결

Step C에서 나온 규모 지표(카테고리 수, 시리즈 수, 노드 수 등)는 `chart-catalog.md`의 "가로형 적합도" 감점 규칙에도 그대로 재사용된다. 예:
- 범주형 고유값이 많은데 "가로 막대"가 후보로 남아있다면 → 감점 후 세로 막대/Top-N으로 전환 권장
- 노드 개수가 매우 많은 Sankey 후보라면 → "상위 N개 + 기타로 묶기" 전처리 제안을 함께 출력

## 전체 흐름 요약

```
Raw 입력
   │
   ├─ 파일 존재? ──Yes──▶ 실측 프로파일링
   │
   └─ No, 설명 텍스트만 ──▶ 추정 프로파일링 (불확실성 인지, 필요시 최소 확인 질문)
   │
   ▼
Step A. 컬럼별 프로파일링
   │
   ▼
Step B. 데이터셋 구조 태그 판별 (복수 가능, 구성 플래그는 후보 상태로만)
   │
   ▼
Step C. 규모 지표 산출 (정성적 판단 포함, 고정 임계치 없음)
   │
   ├──▶ mapping-rules.md의 필수조건/보조조건 판정에 사용
   └──▶ chart-catalog.md의 레이아웃 필터(가로형 적합도)에 사용
```
