# 데이터 성격(패턴 유형) 목록

각 유형은 배타적이지 않다. 하나의 데이터셋이 여러 성격을 동시에 가질 수 있다 (예: 시계열이면서 동시에 다중 시리즈).

| 유형 | 설명 | 예시 | 판별 힌트 |
|---|---|---|---|
| 시계열 (Time Series) | 시간 축을 따라 변화하는 데이터 | 일별 매출, 서버 CPU 사용률 | 날짜/시간 포맷 컬럼 존재 + 시간순 정렬 시 규칙적 간격 |
| 범주형 비교 (Categorical Comparison) | 서로 다른 카테고리 간 값 비교 | 제품별 판매량, 부서별 예산 | 범주형 1개 + 수치형 1개, 행마다 유일 조합 |
| 구성/비율 (Composition) | 전체 대비 각 부분의 비중 | 시장 점유율, 예산 항목 구성 | 컬럼명에 비율/percentage/share 등, 또는 목적 문장에 "차지하는/비중" 표현 |
| 분포 (Distribution) | 값이 어떻게 퍼져 있는지 | 나이대별 인원 수, 응답 시간 분포 | 수치형 컬럼의 각 행이 집계값이 아닌 개별 관측치 |
| 상관관계 (Correlation) | 두 개 이상 변수 간 관계 | 광고비 vs 매출 | 수치형 컬럼 2개 이상, 개별 관측치 단위 |
| 순위 (Ranking) | 값의 크기 순서 | Top 10 판매 상품 | 범주형 + 수치형, 카테고리 수가 많고 정렬 의미가 큼 |
| 프로세스/전환 (Funnel/Flow) | 단계별 전환 또는 유입-유출 흐름 | 가입 퍼널, 트래픽 소스 흐름 | "출발-도착" 성격의 컬럼 쌍 + 이동량(가중치) 수치 |
| 계층 구조 (Hierarchical) | 상위-하위 관계 데이터 | 조직도, 파일 시스템 용량 | 컬럼명에 parent/child/level, 또는 값에 구분자(`/`, `>`) |
| 다변량 (Multivariate) | 3개 이상 지표를 동시에 비교 | 제품별 성능 지표(속도/가격/품질) | 수치형 컬럼 3개 이상 + 개체 식별 범주형 1개 |
| 지리적 데이터 (Geospatial) | 위치 기반 데이터 | 지역별 매출, 국가별 인구 | 컬럼명에 country/region/lat/lng, 값이 지역명·좌표 패턴 |
| 네트워크/관계망 (Network) | 노드 간 연결 관계 | 소셜 네트워크, 조직 커뮤니케이션 | 노드-엣지 구조이나 선형 단계가 아니라 다대다 관계 |
| 단일 지표/KPI (Single Metric) | 목표 대비 단일 수치 | 이번 달 목표 달성률 | 행 수 매우 적음(1~2행) 또는 "현재값-목표값" 컬럼 쌍 |
| 편차/증감 분해 (Deviation/Waterfall) | 누적 증감 분해 | 매출 증감 요인 분석 | 시작값→끝값 사이 증감 요인이 개별 항목으로 분해 가능 |
| 텍스트 빈도 (Text Frequency) | 단어/토큰 출현 빈도 | 리뷰 키워드 분석 | 텍스트 컬럼 + 빈도/카운트 |
| 매트릭스/밀도 (Matrix/Density) | 2차원 격자 형태 값 분포 | 시간대x요일 활동량 히트맵 | 범주형 2개(행/열) + 수치형 1개, 격자 형태로 조합 가능 |

> 이 표는 `scan-procedure.md`의 Step B(구조 태그 판별)에서 실제 판별 로직의 결과 라벨로 쓰인다. 스캔 절차 자체는 `scan-procedure.md`를 참고할 것.
