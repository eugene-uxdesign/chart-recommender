# 의도(목적 문장) × 데이터 구조 매핑 규칙

## 핵심 원칙

사용자는 목적을 자유 문장으로만 입력한다(예: "사용자는 취약점의 다양한 출처로부터 해결까지의 여정을 한눈에 볼 수 있어야 한다"). 아래 11개 **의도 축**은 사용자에게 보여주는 선택지가 아니라, Claude가 문장을 읽고 내부적으로 참고하는 채점 기준표다. 한 문장에서 여러 신호가 동시에 잡혀도 정상이며, 그 경우 주 의도와 부 의도를 구분해서 처리한다 (아래 "다중 의도 처리 원칙" 참고).

각 의도 축은 3단계로 필터링한다:
1. **필수 조건**: 이 데이터 구조가 없으면 해당 차트 자체가 성립 불가 → 데이터에 이 구조가 없으면 이 의도 축 전체를 후보에서 제외
2. **후보 차트**: 필수 조건을 만족했을 때 나올 수 있는 차트들
3. **보조 조건**: 후보가 여럿일 때 규모/성격 세부치로 순위를 가르는 기준 (임계치는 고정 숫자가 아니라 상대적으로 판단 — `scan-procedure.md` Step C 참고)

---

## 1. 비교 (Comparison)
- 문장 신호 예: "~끼리 비교", "누가 더 큰지", "차이를 보고 싶다"
- 필수 조건: 범주형 축 1개 + 수치형 값 1개 이상
- 후보: Bar/Column, Bullet, Dot Plot, Grouped Bar
- 보조 조건: 카테고리 수가 적으면 Bar 그대로 / 많아지면 정렬형·Top-N 고려. 2차 범주(그룹)가 있으면 Grouped Bar. 목표값 대비 비교면 Bullet Chart.

## 2. 추세/변화 (Trend over time)
- 문장 신호 예: "시간에 따라", "점점", "추이", "언제부터 늘었는지"
- 필수 조건: 시간/순서 축 존재
- 후보: Line, Area, Stacked Area, Candlestick
- 보조 조건: 단일 지표 추이 → Line. 여러 카테고리의 누적 총량 추이 → Stacked Area. 시리즈가 색상으로 구분하기 어려울 만큼 많아지면 Small Multiples(패싯) 고려. OHLC형 금융 데이터 → Candlestick.

## 3. 구성/비율 (Composition)
- 문장 신호 예: "얼마나 차지하는지", "전체 중 비중"
- 필수 조건: 부분의 합이 의미 있는 전체(100%)를 이룸. **구성 여부는 Step B에서 확정하지 않고 "후보 플래그"로만 넘어온다** — 컬럼명 > 목적 문장 문맥 > 수치 검증(합산 근사치) 순으로 이 단계에서 최종 확정한다.
- 후보: Pie/Donut, Stacked Bar(100%), Treemap, Icon Array
- 보조 조건: 항목 수가 적으면 Pie/Donut 허용, 많아지면 Stacked Bar 또는 Treemap. 시간에 따른 구성 변화까지 봐야 하면 Stacked Area/Bar(2번과 교차). 계층(상위-하위)까지 있으면 Treemap/Sunburst로 이동(8번과 교차).

## 4. 분포 (Distribution)
- 문장 신호 예: "값들이 어떻게 퍼져있는지", "이상치가 있는지"
- 필수 조건: 연속형 수치 변수의 개별 관측치가 다수 존재(단순 집계값 아님)
- 후보: Histogram, Box Plot, Violin Plot, Strip/Dot Plot
- 보조 조건: 그룹 간 분포 비교 필요 → Box/Violin Plot. 이상치 강조 필요 → Box Plot. 관측치 수가 적으면 개별 점을 살리는 Strip/Dot Plot이 히스토그램보다 정직함.

## 5. 관계/상관 (Correlation)
- 문장 신호 예: "~와 ~가 관련 있는지", "영향을 주는지"
- 필수 조건: 수치형 변수 2개 이상, 개별 관측치 단위로 존재
- 후보: Scatter, Bubble, Heatmap(상관행렬)
- 보조 조건: 변수 2개 → Scatter. 3번째 변수(크기/카테고리)까지 있으면 Bubble. 변수쌍이 다수(전체 상관관계를 보고 싶음) → Correlation Heatmap. 관측치가 매우 많으면 밀도 표현(Hexbin/Heatmap)으로 전환 고려.

## 6. 순위 (Ranking)
- 문장 신호 예: "상위/하위", "가장 ~한", "순서대로"
- 필수 조건: 범주형 축 + 정렬 가능한 수치값, 카테고리 수 많음
- 후보: Ranked Bar(정렬 막대), Lollipop Chart, Bump Chart(순위 변화)
- 보조 조건: 단일 시점 순위 → Ranked Bar/Lollipop. 시간에 따른 순위 변화까지 봐야 하면 Bump Chart(2번과 교차).

## 7. 흐름/여정 (Flow / Journey)
- 문장 신호 예: "~로부터 ~까지", "여정", "유입-이탈", "단계를 거쳐"
- 필수 조건: 노드(단계/출처/상태) 간 이동량(엣지)이 명시적으로 존재 — "A에서 B로 이동한 양"이 데이터에 있어야 함
- 후보: Sankey, Funnel, Alluvial, Process/Journey Map
- 보조 조건: 노드가 **선형 단일 경로**(모두 같은 순서로 단계 통과, 이탈만 발생) → Funnel. 노드가 **다대다 관계**(여러 출처 → 여러 경로 → 여러 결과) → Sankey. 시점별 소속 변화(코호트 이동) → Alluvial. 이동량(엣지 가중치)이 없고 단계 존재 여부만 있으면 Funnel/Sankey 불가 → Step 카드/Stage List로 대체 검토.

## 8. 계층 구조 (Hierarchy)
- 문장 신호 예: "상위-하위 관계", "포함 관계"
- 필수 조건: 상위-하위 포함 관계(parent-child)가 명시적으로 존재
- 후보: Treemap, Sunburst, Tree Diagram, Icicle
- 보조 조건: 크기(비율) 비교가 중요 → Treemap. 계층 깊이+비율 동시에 → Sunburst(단, 와이드 레이아웃에서는 Treemap 우선, `chart-catalog.md` 참고). 순수 구조/관계 전달이 목적(크기 무의미) → Tree Diagram.

## 9. 편차/기여도 분해 (Deviation)
- 문장 신호 예: "무엇 때문에 늘었는지", "증감 요인"
- 필수 조건: 시작값→끝값 사이 증감 요인이 개별 항목으로 분해 가능
- 후보: Waterfall, Diverging Bar
- 보조 조건: 시작-끝 누적 경로가 중요 → Waterfall. 기준값(0) 대비 양/음 방향만 중요 → Diverging Bar.

## 10. 공간 (Spatial)
- 문장 신호 예: "지역별로", "위치에 따라"
- 필수 조건: 위치 식별자(좌표, 국가/지역 코드) 존재
- 후보: Choropleth, Point/Symbol Map, Flow Map
- 보조 조건: 지역 단위 집계값 비교 → Choropleth. 정확한 지점 데이터 → Point Map. 지역 간 이동/흐름까지 있으면 Flow Map(7번과 교차).

## 11. 단일 지표 추적 (Single-value / KPI)
- 문장 신호 예: "목표 대비", "달성률"
- 필수 조건: 목표값(target) 또는 기준값 대비 현재값 1개
- 후보: Gauge, Bullet Chart, Big Number(KPI Card), Progress Ring
- 보조 조건: 목표 대비 구간(양호/주의/위험)까지 표현 필요 → Bullet Chart(와이드 레이아웃에서도 Gauge보다 우선, `chart-catalog.md` 참고). 단순 강조만 필요 → Big Number.

## 다중 의도 처리 원칙

문장 하나에서 의도 신호가 여러 개 나올 수 있다 (예: "여정" + "구성"). 이때:

1. **주 의도(가장 강한 신호)를 1순위 필터**로 적용해 후보를 좁힌다.
2. **부 의도는 별도 차트로 만들지 않고, 인코딩 보조 요소**(색상, 크기, 정렬, 두께)로 흡수한다.

예: "출처별 취약점이 어떤 단계를 거쳐 해결되는지, 그리고 각 출처의 비중도 함께 보고 싶다"
→ 주 의도: 흐름(Flow) → Sankey 확정
→ 부 의도: 구성(Composition) → Sankey의 노드/링크 두께 자체가 비중을 이미 내포하므로 별도 차트 불필요, "링크 두께 = 비율"로 설명만 추가

무리하게 차트 2개를 병렬로 추천하기보다, 하나의 차트가 다의도를 흡수하도록 우선순위를 정한다. 단, 두 의도가 정말 서로 다른 관점(예: 시계열 추이 + 지역별 분포처럼 근본적으로 다른 축)이라 하나의 차트로 흡수 불가능하다면, 그때는 Top 2 후보를 함께 제시해도 된다.
